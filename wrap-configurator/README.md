# Wrap Configurator - Applicazione Completa

## 🚀 Istruzioni per avviare l'app sul tuo computer o hosting web:

### Prerequisiti:
- Node.js versione 18 o superiore installato (scaricabile da https://nodejs.org).

### 1. Installazione dipendenze:
Apri la cartella nel terminale ed esegui:
```bash
npm install
```

### 2. Avvio in locale (Sviluppo):
```bash
npm run dev
```
L'app sarà visibile su: `http://localhost:3000` o `http://localhost:5173`.

### 3. Compilazione per il tuo Hosting Web (cPanel, FTP, Vercel, Netlify, Aruba, Hostinger):
```bash
npm run build
```
Verrà generata la cartella **`dist/`**. Carica tutti i file all'interno di `dist/` nel tuo hosting web (es. cartella `public_html`).

- 🚗 Selezione e configurazione modello furgone (Citroën Berlingo K9, Peugeot Partner, Fiat Doblò, ecc.)

- 📐 Selezione interattiva 5 zone di carrozzeria
- 🖼️ Editor Loghi, QR Code e grafiche vettoriali
